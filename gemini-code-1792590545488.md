# 🚀 Panduan Lengkap Instalasi & Pembaruan Laragon 6 (Full)

Laragon adalah aplikasi *local development environment* yang sangat ringan, cepat, dan fleksibel. Berbeda dengan XAMPP, Laragon memungkinkan Anda menginstal dan berganti berbagai versi PHP, MySQL, atau Node.js hanya dengan satu kali klik.

Panduan ini menggunakan **Laragon versi 6 (Full)** yang sangat stabil. Kita akan menginstalnya lalu memperbarui mesin bawaannya ke versi yang Anda butuhkan secara manual.

---

## 🛠️ Tahap 1: Instalasi Laragon 6

Karena versi 6 sudah sulit dicari di situs resminya, gunakan file *installer* dari arsip di bawah ini:

1. **Unduh File Installer:**
   * 📥 **[Download Laragon 6 Full (.exe) via Google Drive](#masukkan-link-gdrive-anda-di-sini)**
2. **Proses Instalasi:**
   * Jalankan file `.exe` yang baru saja diunduh.
   * **LOKASI INSTALASI (PENTING):** Saat diminta menentukan *Destination Location*, ubah alamatnya menjadi **`C:\laragon\`**. 
     *(🚨 Jangan pernah menaruhnya di dalam folder `C:\Program Files` karena Windows akan memblokir hak akses penulisan database dan file konfigurasi).*
   * Pada jendela **Preferences**, atur centang seperti ini:
     * ✅ **Auto virtual hosts:** (CENTANG) Agar Laragon otomatis membuat domain lokal (contoh: `nama-project.test`) setiap kali Anda membuat folder baru.
     * ❌ **Auto start:** (HILANGKAN CENTANG) Agar Laragon tidak otomatis menyala saat laptop dihidupkan. Nyalakan Laragon manual hanya saat Anda ingin mengerjakan *project* agar RAM laptop tetap lega.
     * ❌ **Notepad++ / Text Editor:** (HILANGKAN CENTANG) Karena kita akan menggunakan VS Code atau *text editor* milik Anda sendiri.
   * Klik *Next* lalu *Install*. Setelah selesai, jalankan aplikasi Laragon.

## 🔄 Tahap 2: Memperbarui Mesin Bawaan (Node.js, PHP, MySQL, Git, Python)

Kelebihan utama Laragon adalah Anda bisa memasukkan lebih dari satu versi *software* secara bersamaan (misalnya PHP 7.4, 8.1, dan 8.3) dan menggantinya sesuka hati tergantung *project* yang sedang dikerjakan. Anda hanya perlu mengunduh file `.zip` resminya dan mengekstraknya!

### 🟢 1. Node.js
* **Link Resmi:** [nodejs.org/en/download](https://nodejs.org/en/download)
* **Cara Update:**
  1. Unduh versi **Windows Binary (.zip)** 64-bit (pilih versi LTS terbaru).
  2. Buka folder `C:\laragon\bin\nodejs\`.
  3. Ekstrak folder `.zip` tersebut ke dalamnya.
  4. Buka aplikasi Laragon ➔ **Klik Kanan** ➔ **Node.js** ➔ **Version** ➔ Pilih versi yang baru diekstrak.
* **⚠️ Error Umum (Node.js tidak muncul di Laragon):**
  * *Penyebab:* Folder hasil ekstrak "beranak" atau ganda (contoh: `nodejs/node-v20/node-v20/node.exe`).
  * *Solusi:* Pastikan file `node.exe` berada tepat di dalam folder utama versinya (contoh: `nodejs/node-v20/node.exe`).

### 🐘 2. PHP (Bisa Multi-Versi)
* **Link Resmi:** [windows.php.net/download/](https://windows.php.net/download/) *(Atau klik menu "Archives" di web tersebut jika butuh versi lawas seperti PHP 7.x).*
* **Cara Update:**
  1. Pilih dan unduh versi yang dibutuhkan berjenis **Thread Safe (TS) - .zip**.
  2. Buka folder `C:\laragon\bin\php\`.
  3. Ekstrak folder `.zip` ke dalamnya. (Anda bisa menaruh banyak folder versi PHP di sini).
  4. **Klik Kanan** Laragon ➔ **PHP** ➔ **Version** ➔ Pilih versi yang ingin digunakan saat ini.
* **⚠️ Error Umum (Apache gagal Start setelah ganti PHP):**
  * *Penyebab:* Windows Anda kekurangan *Visual C++ Redistributable*.
  * *Solusi:* Unduh dan instal "VC Redist x64" dari situs resmi Microsoft.

### 🐬 3. MySQL (Bisa Multi-Versi)
* **Link Resmi:** [dev.mysql.com/downloads/mysql/](https://dev.mysql.com/downloads/mysql/) *(Pilih menu "Archives" untuk mencari versi spesifik).*
* **Cara Update:**
  1. Unduh file **Windows (x86, 64-bit), ZIP Archive**.
  2. Buka folder `C:\laragon\bin\mysql\`.
  3. Ekstrak folder `.zip` tersebut ke dalamnya.
  4. **Klik Kanan** Laragon ➔ **MySQL** ➔ **Version** ➔ Pilih versi MySQL baru Anda.
* **⚠️ Error Umum (MySQL Crash / Gagal Start saat di-upgrade ke versi 8.x):**
  * *Penyebab:* MySQL versi baru menolak membaca file folder `data` lama peninggalan MySQL bawaan Laragon (versi 5.7).
  * *Solusi:* Pergi ke folder `C:\laragon\data\`. Ubah nama folder `mysql` yang ada di sana menjadi `mysql-lama`. Jalankan ulang MySQL di Laragon, sistem akan otomatis membuat folder `mysql` baru yang bersih dan kompatibel.

### 🐍 4. Python
* **Link Resmi:** [python.org/downloads/windows/](https://www.python.org/downloads/windows/)
* **Cara Update:**
  1. Cari rilis terbaru, lalu unduh versi **Windows embeddable package (64-bit)** (file `.zip`).
  2. Buka folder `C:\laragon\bin\python\`. Jika ada folder versi lama, Anda bisa menimpanya atau membuat folder versi baru.
  3. Ekstrak seluruh isi `.zip` ke dalam folder tersebut.
  4. **Klik Kanan** Laragon ➔ **Python** ➔ **Version** ➔ Pilih versi terbaru.

### 📦 5. Git & Composer
* **Update Git (Via Terminal):**
  Buka terminal/CMD bawaan Windows (atau Cmder di Laragon), lalu ketikkan perintah: `git update-git-for-windows`. Git akan otomatis mengunduh dan memperbarui dirinya sendiri.
* **Update Composer:**
  1. **Link Resmi:** [getcomposer.org/download/](https://getcomposer.org/download/) (Gulir ke bawah bagian "Manual Download", unduh file **`composer.phar`** terbaru).
  2. Buka folder `C:\laragon\bin\composer\`.
  3. Timpa (Replace) file `composer.phar` yang lama dengan file yang baru saja Anda unduh.

## 🔗 Tahap 3: Mendaftarkan Path ke Sistem Windows (Wajib)

Agar perintah seperti `php`, `node`, `git`, `composer`, dan `python` bisa Anda ketik dan eksekusi dari Terminal VS Code atau Command Prompt biasa, mesin-mesin tersebut harus didaftarkan ke *Environment Variables* Windows. 

Gunakan fitur aman dari Laragon untuk melakukannya:
1. Buka aplikasi **Laragon**.
2. **Klik Kanan** di area kosong ➔ **Tools** ➔ **Path** ➔ klik **Add Laragon to Path**.
3. Selesai! Laragon akan mendaftarkan sistemnya ke *User Variables* Windows Anda secara otomatis.

> [!WARNING]
> **TROUBLESHOOTING: Jika Perintah Tetap "Not Found" di VS Code / Terminal**
> 1. **Refresh Terminal:** Windows tidak mendeteksi perubahan *Path* secara langsung. **Tutup total** aplikasi VS Code atau CMD Anda, lalu buka kembali agar *Path* yang baru ikut dimuat.
> 2. **Hindari 'Run as Administrator':** Buka VS Code secara biasa. Jika dijalankan sebagai Administrator, terminal sering gagal membaca profil *User Variables* Anda.
> 3. **Cek Bentrok di System Variables:** Jika dulu Anda pernah menginstal Node.js/Python dari `.exe` lain, *path* lamanya mungkin tersangkut di pengaturan *System Variables*. Windows selalu mengutamakan *System* daripada *User*. Cari dan hapus *path* lama di *System Variables* agar mesin dari Laragon bisa terbaca!
