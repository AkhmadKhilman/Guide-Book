# Daftar Bahasa & Format dalam Fenced Code Blocks

1. Bahasa Pemrograman (Programming Languages)
   • javascript atau js (JavaScript)
   • typescript atau ts (TypeScript)
   • python atau py (Python)
   • java (Java)
   • csharp atau cs (C#)
   • cpp atau c++ (C++)
   • go atau golang (Go)
   • rust atau rs (Rust)
   • kotlin atau kt (Kotlin)
   • swift (Swift untuk iOS)
   • ruby atau rb (Ruby)

2. Desain Web & Format Data (Web & Data Formats)
   • html (HyperText Markup Language)
   • css (Cascading Style Sheets)
   • json (JavaScript Object Notation)
   • yaml atau yml (YAML - Sering untuk file konfigurasi seperti pubspec.yaml di Flutter)
   • xml (Extensible Markup Language)
   • toml (Tom's Obvious Minimal Language)

3. Terminal, Shell, & Database
   • bash atau sh (Perintah terminal Linux/macOS)
   • powershell atau ps1 (Terminal modern Windows)
   • cmd atau bat (Command Prompt Windows klasik)
   • sql (Structured Query Language untuk database seperti MySQL, PostgreSQL, SQLite)

4. Format Khusus & Teks Polos
   • markdown atau md (Untuk mendokumentasikan kode Markdown itu sendiri)
   • diff (Untuk menunjukkan perbandingan baris yang ditambah + atau dihapus -)
   • text atau plaintext (Untuk teks/catatan biasa tanpa pewarnaan otomatis, hanya dibungkus kotak abu-abu)
