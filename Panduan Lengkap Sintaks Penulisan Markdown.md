```md
1. Struktur Judul (Headings)

   # Judul Utama Level 1 (Terbesar)

   ## Subjudul Level 2

   ### Subjudul Level 3

   #### Subjudul Level 4

   ##### Subjudul Level 5

   ###### Subjudul Level 6 (Terkecil)

2. Format Teks (Text Styling)

   Membuat teks menjadi **Cetak Tebal** menggunakan dua bintang.
   Membuat teks menjadi _Cetak Miring_ menggunakan satu bintang.
   Membuat teks menjadi **_Tebal dan Miring_** menggunakan tiga bintang.
   Membuat teks ~~Dicoret (Strikethrough)~~ menggunakan dua tanda tilde.

3. Daftar (Lists)
   - Daftar Tanpa Nomor (Bullet Points): Gunakan tanda bintang \*, minus -, atau plus +
     - Item Pertama
     - Item Kedua
       - Sub-item kedua (Gunakan tab/spasi)

   - Daftar Berurutan (Numbered Lists): Gunakan angka diikuti titik
     1. Langkah Pertama
     2. Langkah Kedua
     3. Langkah Ketiga
   - Daftar Tugas (Task List / Checklist)
     - [x] Tugas yang sudah selesai dikerjakan
     - [ ] Tugas yang belum selesai dikerjakan

4. Kutipan (Blockquotes)

   > **Catatan Penting:** Jangan pernah menghapus file konfigurasi ini tanpa melakukan backup terlebih dahulu.

5. Link dan Gambar
   - Memasukkan Link URL: [Teks Link](Alamat URL)markdown

     Silakan kunjungi [Google](https://google.com) untuk mencari informasi.

   - Memasukkan Gambar: ![Teks Alternatif jika gambar error](Alamat URL atau Path Gambar)

     ![Logo Markdown](https://markdown-here.com)

6. Membuat Tabel (Tables)
   Gunakan tanda garis tegak | untuk kolom dan tanda minus - untuk baris pembatas judul tabel.

   | Nama Anggota | Peran dalam Tim | Status |
   | :----------- | :-------------- | :----- |
   | Budi Santoso | Lead Developer  | Aktif  |
   | Siti Aminah  | UI/UX Designer  | Cuti   |

7. Garis Pembatas Horizontal (Horizontal Rule)

   ***

8. Kode di Dalam Kalimat (Inline Code)

   Gunakan perintah `flutter run` di terminal untuk menjalankan aplikasi.
```
